# EJU 20-Day Speed Run: Math + Biology + Chemistry

**Target Exam:** EJU 2026 (1st Session)
**Subjects:** Mathematics (Course 2), Biology, Chemistry

---

## How to Use This Guide

Each day has ONE file in the `days/` folder. Every file covers **all 3 subjects** for that day.

- Read every section carefully — don't skip the examples.
- Do the practice problems before looking at the answers.
- If something confuses you, re-read the explanation from the top.
- Review the previous day's summary before starting a new day.
